# Shipaton quickstart

RevenueCat’s global mobile hackathon context — reusable across Shipaton IRL events.

## What Shipaton is

Ship a **brand-new** app in the window, use **RevenueCat**, compete for prizes.

| | |
|--|--|
| Window | **1 August – 30 September 2026** |
| Home | https://www.shipaton.com |
| Rules / submit | https://revenuecat-shipaton-2026.devpost.com/ |
| IRL calendar | https://www.shipaton.com/events |
| Ship Kit | https://www.shipaton.com/ship-kit |
| Livestreams | https://www.shipaton.com/live |

## The challenge (short)

- Ship a **new** iOS, macOS, or Android app  
- First version released **in the window** on App Store, Google Play, or Samsung Galaxy Store  
- Uses the **RevenueCat SDK** for in-app purchases or RevenueCat Ads  

Students: check the **Next Gen** path on shipaton.com (video + source option).

## Do this now

- [ ] Open shipaton.com and register / continue on Devpost  
- [ ] Join the Shipaton Discord (link from shipaton.com)  
- [ ] Skim Ship Kit perks (while supplies / milestones last)  
- [ ] Bookmark official rules — don’t rely on memory for eligibility  

## Local IRL vs global prizes

**On the day (typical IRL):** build · demo · room vote · local merch.  

**Global:** submit on Devpost by the deadline · official judging · see shipaton.com for current prizes.

Event packs add room-specific QRs, vote links, and timing — not this page.
