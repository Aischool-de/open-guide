# Scope contract

Use before writing code. Locks one user, one action, one visible result.

```text
We are building a short MVP. Our scope contract:

- User: [one person]
- Problem: [one painful job]
- Version 1 action: [one action]
- Visible result: [one output]
- Done when: [one testable statement]

Before writing code:
1. Note 2–3 comparable patterns or UX references (brief bullets).
2. Choose the smallest vertical slice that satisfies "Done when".
3. Create short Markdown files in /docs for product brief, requirements,
   architecture, UI notes, build plan, and test notes (mark unknowns TBD).

Show me the plan for approval before implementation.
```
