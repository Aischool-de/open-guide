# Unstuck

Evidence-first debug prompt. Pair with [Unstuck: evidence first](/ai-building/unstuck-evidence-first).

```text
I am stuck. Work evidence-first — do not guess.

Expected: [what should happen]
Actual: [what happened instead]
Evidence: [error message, screenshot description, or terminal output]

1. Reproduce the issue
2. State one hypothesis
3. Propose the smallest change to test it
4. Tell me exactly what command or click path verifies the fix
```
