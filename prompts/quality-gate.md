# Quality gate

Before-demo checklist as a prompt. Pair with [Quality gate before demo](/ai-building/quality-gate-before-demo).

```text
Run a quality gate before we demo. Check each item PASS or FAIL:

- Core user flow works end-to-end
- Empty and invalid input handled gracefully
- No secrets or API keys in source
- App runs without obvious crashes
- Demo path is clear in under 90 seconds

List failures in priority order and fix them one at a time.
```
