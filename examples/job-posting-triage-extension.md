# Example: job posting triage extension

Reusable product shape from live workshops. Not tied to one city or date.

## Job to be done

High-volume applicants paste or open a posting and get **🟢 Apply / 🟡 Maybe / 🔴 Skip** against a Markdown profile — decide in seconds, not minutes.

## Why it fits a short MVP

- One user (job seeker)  
- One action (triage a posting)  
- One visible result (color decision + short reason)  
- Easy to demo in under 90 seconds  

## Suggested stack (flexible)

Chrome extension or small web app · Markdown profile · LLM classify with a strict output schema · local storage for the profile.

Use [BRD v1](/prompts/brd-v1) and [Scope contract](/prompts/scope-contract) to lock your own variant.
