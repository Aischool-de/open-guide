# Vibe coding loop

How Ai School uses the phrase — not “accept every AI suggestion.”

1. Say what you want in your own words  
2. Let AI draft the implementation  
3. Inspect the plan and the diffs  
4. Run and test  
5. Iterate  

If you skip step 3 or 4, you are gambling, not building.
