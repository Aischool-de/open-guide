# Sprint checklist

Reusable mid-workshop checklist. Event packs may add local timing; keep this list product-agnostic.

## Team (2–5 people works well)

- [ ] Who is **driver** (types)?  
- [ ] Who is **navigator** (prompts / checks)?  
- [ ] Who tracks **time** and demo path?  

Solo is fine — pair with a mentor when stuck.

## Build order

- [ ] Empty project + Git  
- [ ] One screen that shows the primary action  
- [ ] One complete flow with sample data  
- [ ] Basic empty/error states  
- [ ] (Optional) Partner SDK stub / docs skim — only if time  
- [ ] Rehearse **60–90s** demo once  

## Stop rules

- If it’s not demoable in 90 seconds, **cut scope**.  
- Pretty UI after the flow works.  
- Store submission and certificates are **after** the live sprint — don’t burn the clock on them.
